# Figure captions

## Main architecture

Architecture of the dimension-specific local attention network (DLAN). (a) Query attributes and coordinates are encoded into a query token; retrieved training observations provide reference key tokens and response-enriched value tokens. Bandwidth-adaptive retrieval takes the union of the nearest references under the block–head distance metrics. Each of the L attention blocks updates only the query state, using geographical cross-attention, residual connections, layer normalisation and a feed-forward network. The final state conditions the nonlinear predictor whilst the query attributes retain a direct prediction path. (b) Parallel branches explicitly show coordinates a=1,2,…,D within one block and head. Each branch produces its own content score cₐ, directional bias gₐ and Gaussian log prior pₐ, using independent coordinate-specific projections and scales. The content scores are averaged and the geographical terms are summed before ONE masked softmax over the shared candidate identifiers j. The resulting weights α̃ᵢₕⱼ, after training-time dropout, are distributed unchanged to every coordinate-specific value pooling branch. The contexts are concatenated across coordinates and heads before output projection. The construction repeats for every attention head; no coordinate branch has a separate softmax. (c) At each of R hidden layers, the local condition generates a bounded scale 1+tanh(γ) and an additive shift β, followed by GELU and dropout. The final readout is linear. The symbol ⊙ denotes elementwise multiplication; ×L and ×R denote independently parameterised repeated blocks and hidden layers. Observed reference responses enter values; the query response is absent from all prediction inputs.

The feature token is e = LN[Eₓ(x)+E_z(z)], where E_z applies Fourier features and a learned projection. All Q/K/V and FiLM projections are affine. Add & Norm includes dropout before residual addition; the feed-forward sublayer also contains dropout. Each FiLM parameter generator is initially zero, giving unit scale and zero shift. These details are expanded in the accompanying mechanism figures.

## Attention detail

Dimension-wise scoring and joint attention in DLAN. The three displayed branches represent coordinates 1, 2 and D, with ellipses indicating any intervening coordinates. For fixed block ℓ and head h, each coordinate has independent Qₐₕ, Kₐₕ and Vₐₕ projections. Its content score is cₐ=qₐᵀkₐ/√dₕ; its directional bias gₐ is the corresponding output of a coordinate-specific MLP receiving (δₐ, |δₐ|, sgn δₐ); its Gaussian log prior is pₐ=−½(δₐ/bℓₐₕ)². Here δₐ=zⱼₐ−zᵢₐ. Query, reference, block and head indices are suppressed in cₐ, gₐ, pₐ and the per-branch formulas for readability. The joint score is s=(1/D)Σₐcₐ+Σₐgₐ+Σₐpₐ. All branches use the same retrieved reference identifiers. Exactly one masked softmax per head is applied after this fusion. Purple connectors distribute the same post-dropout attention weights α̃ᵢₕⱼ to all coordinate-specific value pools; green arrows carry each branch's own projected values. The contexts are concatenated and projected back to d dimensions. Positive scales are bℓₐₕ=softplus(ρℓₐₕ)+10⁻⁶. Reference key/value tokens remain fixed across blocks within one forward pass.

## FiLM detail

Conditionally modulated nonlinear prediction. The same final query condition hᵢ supplies each hidden layer with its own affine scale/shift generator. The bounded scale 1+tanh(γ) multiplies the linear feature activations; β supplies an additive shift. GELU and dropout precede the next hidden layer. All FiLM generators are zero-initialised, and the final response readout is linear. Layer widths may differ; R denotes the number of hidden layers.
